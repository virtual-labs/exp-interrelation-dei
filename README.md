### About the Experiment 

This experiment focuses on simulating the integration between ESP8266/ESP32 modules and major cloud platforms.  
It demonstrates how IoT devices transmit data to cloud services such as AWS, Microsoft Azure, ThingSpeak, and IBM Bluemix.  
Students learn cloud authentication, API-based communication, and remote data storage mechanisms.  
The experiment introduces platform-based IoT architecture and device-to-cloud connectivity concepts.  
The simulation provides practical understanding of scalable cloud-based IoT deployments.
